# LUMINA — ตะวันและจันทรา (2-Player Mobile Co-op Adventure)

เกมผจญภัย 2 มิติแบบ Co-op **10 ด่าน 5 ดินแดนเรืองแสง** สำหรับเล่น 2 คนบนมือถือคนละเครื่อง (หรือเล่นคนเดียวพร้อมคู่หู AI) เน้นภาพบรรยากาศป่าเรืองแสง น้ำตก แสงเงาเรียลไทม์ ระบบ Tutorial + คำใบ้ประจำด่าน และเสียงประกอบ/ดนตรีสังเคราะห์สดด้วย Web Audio API

## พลังของคู่หู

- **SOLA (โซลา · เปลวตะวัน)** — ยิง **ลำแสงสุริยะ** ใช้เผาเถาวัลย์เงา จุดเสาสุริยัน และโจมตีจุดอ่อนธาตุตะวัน
- **LUNA (ลูนา · แสงจันทรา)** — ยิง **คลื่นจันทรา** ใช้กระตุ้นผลึกสีฟ้าเพื่อเสกสะพานแสง และชะลอศัตรู
- **ร่วมใจกัน** — เหยียบหัวคู่หูเพื่อพุ่งตัวสูง, กด **ผสานพลัง** เมื่ออยู่ใกล้กันเพื่อฟื้นฟูพลังชีวิตทั้งคู่หรือปลุกเพื่อนที่กลายร่างเป็นวิญญาณ

## ระบบ Tutorial, คำใบ้ และ 10 ด่านผจญภัย

- **คู่มือฝึกก่อนเริ่ม (Pre-Game Tutorial)**: สอนบทบาท การควบคุม ท่าประสานพลัง และกลไกบอส 4 หน้า พร้อมปุ่มเปิดดูซ้ำได้ทั้งจากหน้าแรกและเมนูพักเกม
- **ภารกิจฝึกหัดด่าน 1**: ด่านที่ 1 (`ลานฝึกหิ่งห้อย`) มีเช็กลิสต์โต้ตอบแบบเรียลไทม์และเสียงติ๊งเมื่อผ่านแต่ละบทเรียน
- **ปุ่ม `💡 คำใบ้` (กด `I`)**: เปิดดูเป้าหมายและคำใบ้เฉพาะของทั้ง 10 ด่านได้ทุกเวลา พร้อมปุ่มเลือกข้ามไปเล่นด่าน 1–10 ใน Lobby และเมนูพักเกม
- **10 ด่าน 5 ไบโอม**:
  1. ลานฝึกหิ่งห้อย (`forest`) — Tutorial
  2. ป่าหิ่งห้อยกระซิบ (`forest`)
  3. หุบเขาน้ำตกหมอก (`forest`)
  4. ยอดไม้แสงเหนือ (`canopy`)
  5. หอคอยลมสุริยะ (`canopy`) — มินิบอส **วิญญาณวายุเงา**
  6. ถ้ำน้ำตกผลึก (`cavern`)
  7. เขาวงกตสะท้อนแสง (`cavern`)
  8. ซากวิหารจันทรา (`abyss`)
  9. ทางเดินแห่งสุริยุปราคา (`abyss`)
  10. วิหารสุริยุปราคา (`sanctuary`) — บอสใหญ่ **อัมบรา นอคทิส**

## วิธีติดตั้งและเปิดเซิร์ฟเวอร์

```bash
npm.cmd install
npm.cmd start
```

## การควบคุมและเสียง

- **มือถือ**: วงกลมฝั่งซ้ายเพื่อเดิน, ปุ่มฝั่งขวาเพื่อ **กระโดด** (กด 2 ครั้งเพื่อ Double Jump), **ใช้พลัง** (สุริยะ/จันทรา), **ผสานพลัง**, และ **เรียกคู่หู**
- **คีย์บอร์ด (PC)**: `A / D` หรือ `← / →` เดิน, `Space / W / ↑` กระโดด, `J / E / Shift / Enter` ยิงพลัง, `K / Q` ผสานพลัง, `H / C` เรียกคู่หู, `I` เปิดคำใบ้, `Tab` สลับตัวในโหมด AI
- **ปรับแต่งเสียง**: เปิด/ปิดเสียงได้ที่ปุ่ม `🔊` หรือปรับระดับเสียงเพลงประกอบ (BGM) และเสียงเอฟเฟกต์ (SFX) แยกกันในเมนูพักเกม
